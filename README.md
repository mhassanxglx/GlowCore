# GlowCore

GlowCore is an Auto-Optimized Service Platform that leverages real-time-processing and auto-scaling for high-throughput data aggregation and analysis.

With GlowCore, you get a lightweight tool that stays out of your way.

**What you get**

- GlowCore is an Auto-Optimized Service
- Platform that leverages real-time-processing and
- auto-scaling for high-throughput data aggregation

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/GlowCore.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure GlowCore, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
